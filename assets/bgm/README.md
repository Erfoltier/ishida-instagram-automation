# リール用BGM

このフォルダに音源ファイル（`.mp3` / `.m4a` / `.aac` / `.wav`）を置くと、リール動画にBGMとして自動で入ります。

- 複数置いた場合は、リールごとに1曲が選ばれます（同じリールを作り直しても同じ曲になります）
- 動画より短い曲はループし、冒頭と最後の1.5秒はフェードイン・フェードアウトします
- 音量は `remotion/Reel.tsx` の `BGM_VOLUME` で調整できます
- 1曲も置いていない場合は無音で書き出し、承認Issueに警告を表示します

## 音源の条件（必ず確認してください）

- **商用利用可・クレジット表記不要**で、**SNS（Instagram）への投稿が許可**されている音源だけを置いてください
- 市販曲・テレビ・他人の動画から切り出した音源は使えません
- このリポジトリは Public のため、置いたファイルは誰でもダウンロードできる状態になります。再配布が禁止されている音源（多くの有料ストック音源が該当）は置かないでください

Instagramアプリ側の音源（トレンド曲など）を使いたい場合は、ここには何も置かず、Instagramアプリで動画を投稿し直す運用になります（API経由ではアプリ内の音源を付けられません）。
