# いしだ皮フ科 リール制作ベースルール

このアカウント（@ishidabiyou）で Remotion のリールを作るときの共通ルール。新しいリールを作る・テンプレートを変えるときは、必ずこのルールに沿っているか確認する。個別の依頼でユーザーが違う指示をした場合（例：「今回はBGMなし」）は、その指示を優先する。

## 1. 根拠にしている調査（2026年10月）

| 分かったこと | 出典 |
|---|---|
| 続けて見るかは**最初の0.5〜2秒**で決まる。タイトルカードやゆっくりした導入は避け、いちばん強い一言を1フレーム目に置く | [Hootsuite](https://blog.hootsuite.com/instagram-reels/)、[tatap](https://tatap.jp/knowledge/insta_reels2/) |
| **半数以上が音声オフ**で見る。テロップは1秒目から出し、音がなくても内容が全部伝わるようにする | [マーケティングワン](https://marketingone.co.jp/instagram-reels-cvr-creative-guide-2026/) |
| **1〜2秒ごとに画面が変わるテンポ**と、**保存したくなる要素（見返す価値）**が伸びるリールの共通点。終わりと冒頭がつながるループ構造も有効 | [Slooooth](https://media.slooooth.com/instagram-reel-number-of-views/) |
| 教育系の美容リールのBGMは、**歌詞のないlo-fi・チルハウス**が主流（情報の邪魔をしない） | [heytrendy](https://heytrendy.app/blog/trending-audio-for-instagram-reels) |

## 2. 構成

- **冒頭（2小節≒4秒）**：1フレーム目から問いかけ・結論を表示する。フェードインで文字が見えない時間を作らない
- **本編**：1シーン1論点。1シーンは2〜3小節（4〜6秒）以内とし、シーン内でも1拍ごとに何かが動く・出る状態にする
- **締め**：クリニック名・アクセス・予約導線（「プロフィールの公式LINEから」）と、**「保存して見返してね」のような保存の呼びかけ**を入れる
- 尺の目安は30〜35秒。カルーセルを動画化する場合も、50秒を超えたらシーンを削る
- 数字・比較・出典があると保存されやすい。研究の数値を出すときは、**画面に出典（著者・誌名・年）を小さく表示する**

## 3. 見飽きさせない動きのルール

使う動き（実装は `remotion/ReelPop.tsx` と `remotion/CarouselReel.tsx`）：

| 仕掛け | 使いどころ | 実装 |
|---|---|---|
| 1字ずつ跳ねて出る文字（テロップのタイピング風） | 見出し | `PopChars`（日本語は `Intl.Segmenter` で単語ごとにまとめ、変な位置で改行しない） |
| 蛍光ペンを引くマーカー | 見出しのキーワード。**文字が出たあとに**左から右へ引く | `MarkedTitle` / `Marker` |
| 白い帯に載った大きな文字を、拍に合わせて叩き込む | 冒頭のフック | `SlamLine` |
| カウントアップ（0→3,000 など） | 量・回数など主役の数字 | `StatBody` |
| 伸びる比較バー＋倍率スタンプ（「約3〜5倍」） | 一般的な量と研究の量など、2つの比較 | `CompareBody` |
| 行ごとに下から浮き上がる本文 | 本文・注記 | `Rise` / `rise` |
| 弾むポップ | 数字・バッジ・アイコン付きのチップ | `pop` / `CheckPill` / `IconChip` |
| カットごとの白フラッシュ＋ズーム、写真のゆっくりしたズーム | シーンの切り替え | `CutFlash` / `PhotoBg` |
| 画面上部の進行バー | 本編全体（あと何シーンか分かる） | `Progress` |
| 「保存版」ステッカー、保存アイコンが弾むCTA | 冒頭・締め | `HookScene` / `ClosingScene` |

ルール：
- 画面が**1拍（約0.5秒）以上止まらない**ようにする。全部の文字を一度に出さず、読む順番に出す
- ハイライト・下線・吹き出しの縁は、背景ではなく**文字の装飾として扱い、文字のあとに描く**
- 文字の動きは速く（0.3〜0.5秒）、読む時間は長く。シーンの前半55%で全部出し終え、残りは読ませる
- 拍に合わせる場合は **112.5BPM＝1拍16フレーム（30fps）** を基準にし、シーンの切り替えを小節の頭に置く（BGMなしでもこのテンポ感で組む）

## 4. 画面・文字

- 1080×1920・30fps・H.264。文字はInstagramのUIと重ならない範囲に入れる（上250px・下380px・右約160pxを避ける）
- フォントは Noto Sans JP（太字は800〜900）を基本にし、ブランドの文字色（`#2E2629` 系）と、テーマごとのアクセント色を1色使う
- カルーセル画像を動画化する場合は、**画像のフォント・色調を崩さない**。`scripts/carousel-reel/prepare.py` で文字・ハイライトと背景を分け、元画像から切り出した文字を動かす
- 文字の改行位置は、静止画で必ず確認する（「シ／ミも」のような1文字だけの改行を残さない）

## 5. 内容・表現（医療広告・薬機法）

- **価格は動画に入れない**。投稿後に動画は差し替えられないため、価格はあとから編集できるキャプションにだけ書く（「※料金は投稿時点のものです」と料金表のリンクを添える）
- 他院の名前は出さない。比べる対象は「一般的な処方量」など一般論にする（比較優良広告の回避）
- 効果を言い切らない（「効かない」「必ず」「安全です」などは使わない）。研究の結果は「報告されています」と書き、出典を示す
- サプリ（食品）は効能を書かない（ソルプロは「紫外線対策サプリメント」まで）
- 肝斑のトラネキサム酸を保険と結びつけない。保険診療に触れるときは「シミの種類や肌の状態によっては、保険診療で治療できるものもあります」の一般論にとどめる
- 自費診療を紹介するときは、費用と主なリスク・副作用をキャプションに書く

## 6. 画像・音楽

- AIで生成する背景画像には、**文字・製品パッケージ・人物・医療機器を入れない**。当院の過去の投稿（ビタミンC 3000、セベリアバーム、ソルプロなど）を色調・雰囲気の参考にする
- BGMは著作権の心配がない自作音源を使う（`scripts/music/chill-house-bgm.py`、112.5BPMのチルハウス）。市販曲や他人の動画の音は使わない
- ユーザーが「BGMなし」と指定した場合は無音で書き出す（Instagramアプリから投稿するときにアプリ内の音源を付ける運用もある）

## 7. 書き出し前の確認

1. 0秒・0.5秒・1秒のフレームを書き出し、**1フレーム目に何の話か分かる文字が出ているか**
2. 各シーンの最後のフレームで、文字の欠け・重なり・不自然な改行・消し残しがないか
3. カルーセル画像を使った場合、各シーンの最後のフレームが元の画像と同じ見た目か
4. `ffprobe` で 1080×1920・30fps・H.264 になっているか（BGMありならAACの音声も）

## 8. 投稿まわりで分かっていること

- Meta Business Suite では、**Instagramのリールは下書き保存できない**（仕様）。公開前に置いておきたいときは「日時を指定」で予約投稿にする
- Business Suite の下書きは API で取得できない。下書きの画像を動画にするときは、画像をチャットに貼ってもらうか、Googleドライブ経由で受け取る
